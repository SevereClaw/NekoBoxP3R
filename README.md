# NekoBoxP3R

Сборка [NekoBox (nekoray)](https://github.com/MatsuriDayo/nekoray) 4.0.1 в стиле **Persona 3**: своя тема интерфейса и значок.

## Что изменено
- Новая встроенная тема **Persona 3** (`res/theme/p3r/p3r.css`), включена по умолчанию.
  Переключение: Настройки → Основные настройки → Тема.
- Новый значок программы (`res/nekobox.ico`, `res/public/nekobox.png`).
- Большая кнопка **ПОДКЛЮЧИТЬСЯ / ОТКЛЮЧИТЬСЯ** над списком серверов. Подключает выбранный сервер,
  если ничего не выбрано, то последний использованный, иначе первый в списке.
- **Упрощённый режим** (включён по умолчанию, переключается в меню «Программа»): скрыты лог, соединения,
  колонки «Тип» и «Трафик», кнопки «Реклама», «Документация», «Обновление».
- Подсказки при наведении на «VPN» и «Системный прокси».

## Скачать
- Готовая сборка после каждого коммита: вкладка **Actions** → последний запуск → артефакт `NekoBoxP3R-windows64`.
- Релизы: вкладка **Releases**. Новый релиз создаётся автоматически, когда в `p3r_version.txt` меняется версия.
