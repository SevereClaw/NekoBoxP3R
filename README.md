# NekoBoxP3R

Сборка [NekoBox (nekoray)](https://github.com/MatsuriDayo/nekoray) 4.0.1 в стиле **Persona 3**: своя тема интерфейса и значок.

## Что изменено
- Новая встроенная тема **Persona 3** (`res/theme/p3r/p3r.css`), включена по умолчанию.
  Переключение: Настройки → Основные настройки → Тема.
- Новый значок программы (`res/nekobox.ico`, `res/public/nekobox.png`).
- Большая кнопка **ПОДКЛЮЧИТЬСЯ / ОТКЛЮЧИТЬСЯ** над списком серверов. Подключает выбранный сервер,
  если ничего не выбрано, то последний использованный, иначе первый в списке.
- **Упрощённый режим** (включён по умолчанию, переключается в меню «Программа»): скрыты лог, соединения,
  колонки «Тип» и «Трафик», кнопки «Реклама» и «Документация».
- Подсказки при наведении на «VPN» и «Системный прокси».
- **Обновления из этого репозитория**: при запуске и каждые 6 часов программа проверяет Releases и предлагает
  обновиться (скачивает zip и ставит через `updater.exe`, настройки в `config` сохраняются).
  Вручную: Программа → Проверить обновления или кнопка «Обновление». Автопроверку можно выключить там же.

- **Анимации и звуки в духе P3R**: скошенный баннер с выездом при запуске, кнопка подключения
  со скошенной формой, ховером и «вспышкой», выезд меню, плавное появление окон; свои синтезированные звуки
  (меню, подключение, отключение). Выключаются в меню «Программа».
- Своё название **NekoBoxP3R** (заголовок окна, трей, свойства exe) и окно **«О программе»**.

- **Пинг серверов видно сразу**: цветная скошенная плашка и «полоски сигнала»: зелёный — быстрый,
  жёлтый — средний, оранжевый — медленный, красный — недоступен. Таблица крупнее и контрастнее.
- **Значок в трее** с крупной меткой статуса в обводке: зелёная — подключено, голубая — системный прокси,
  фиолетовая — VPN для всех программ. Нет метки — не подключено.

- **Самый быстрый сервер**: галочка «Самый быстрый» рядом с кнопкой (включена по умолчанию) — кнопка
  ПОДКЛЮЧИТЬСЯ сама проверяет пинг всех серверов группы и подключается к лучшему. Также: Сервер → Подключиться к самому быстрому.
- **Понятные названия и подсказки**: «VPN для всех программ», «Браузер и программы с прокси», «Режим работы»,
  «Проверить пинг», «Быстрый пинг (TCP)» и т.д., с пояснениями при наведении.

- **VPN без окна UAC**: Программа → «VPN без запроса прав администратора» (или кнопка «Всегда, без запроса»
  при первом включении VPN). Один раз создаётся задача в Планировщике Windows с наивысшими правами, дальше программа
  при обычном запуске сама перезапускается через неё — без вопросов. По умолчанию включено «Подключаться при запуске
  (последний сервер и VPN)». Если перенесёшь папку программы — выключи и снова включи эту настройку.

- **Российские сайты напрямую** (галочка у кнопки подключения, включена по умолчанию): .ru / .su / .рф,
  Госуслуги, банки, Яндекс, VK, Mail.ru и российские IP открываются без прокси, остальное — через сервер.

- **Автопереключение**: каждые 20 с проверяется текущий сервер; если он дважды подряд не ответил — программа
  проверяет группу и переключается на самый быстрый, с уведомлением Windows. Если не отвечает ни один — сообщает,
  что, возможно, пропал интернет.
- **Kill switch** (Программа → «Kill switch», выключен по умолчанию): в режиме «VPN для всех программ», если соединение
  неожиданно оборвалось, брандмауэр Windows блокирует весь трафик, кроме ядра программы, пока VPN не вернётся.
  Также включает strict route для TUN. Снять вручную: Программа → «Разблокировать интернет» (снимается и при выходе).

- **Программы и VPN** (кнопка «Программы...» у кнопки подключения): «эти программы напрямую» (например, игры)
  или «только эти через прокси» (например, только Discord). Выбор из запущенных, exe-файлом или по имени.
- **Уведомления Windows**: подключение/отключение (когда окно в фоне), смена сервера, kill switch, обновления.
- **Горячая клавиша** подключить/отключить из любой программы: по умолчанию Ctrl+Alt+P
  (меняется в Настройки → Горячие клавиши).

## Скачать
- Готовая сборка после каждого коммита: вкладка **Actions** → последний запуск → артефакт `NekoBoxP3R-windows64`.
- Релизы: вкладка **Releases**. Новый релиз создаётся автоматически, когда в `p3r_version.txt` меняется версия.
